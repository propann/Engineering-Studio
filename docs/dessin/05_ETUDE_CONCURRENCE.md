# Étude concurrentielle — repères pour une interface crédible

Cette étude ne cherche pas à copier les marques. Elle relève les conventions
que l’utilisateur comprend déjà dans les produits de musique portables.

## 1. Teenage Engineering — OP‑1 / EP‑133

Les pages officielles présentent l’OP‑1 comme un instrument tout-en-un avec
synthèse, sampler, séquenceur, effets et Tape. L’OP‑1 original insiste aussi
sur l’interface colorée, l’écran 320×160 et les modes USB audio/MIDI/mass
storage. L’EP‑133 met en avant le passage rapide de l’idée au morceau, les
samples, MIDI/sync, la mémoire et un guide en ligne.

Sources : [OP‑1 original](https://teenage.engineering/products/op-1/original),
[OP‑1 Field](https://teenage.engineering/products/op-1),
[EP series](https://teenage.engineering/products/ep),
[guide EP‑133](https://teenage.engineering/guides/ep-133).

**À retenir pour nous :** préserver une identité instrumentale forte, garder
les états et couleurs très lisibles, mais ajouter la clarté d’un logiciel
moderne pour les sauvegardes, les fichiers et les confirmations.

## 2. Ableton Note

Ableton Note sépare clairement bibliothèque de Sets, Session View, instruments,
capture, édition MIDI, samples, export et transfert vers Live via Cloud. Le
manuel officiel décrit aussi les états locaux/cloud et les actions de Set
(dupliquer, renommer, exporter, partager).

Sources : [page Note](https://www.ableton.com/en/note/),
[manuel Note](https://www.ableton.com/en/note/manual/).

**À retenir pour nous :** séparer bibliothèque et espace de création ; donner
un accès constant à lecture, capture, annuler/rétablir et export ; rendre les
transferts explicites au lieu de les cacher dans les réglages.

## 3. Koala Sampler

Koala met l’accent sur une boucle très courte : enregistrer ou importer,
jouer sur les pads, découper, régler pitch/pan/volume, ajouter des effets,
séquencer et exporter. Sa page officielle annonce jusqu’à 64 samples, huit
effets et des exports audio.

Source : [Koala Sampler](https://www.koalasampler.com/).

**À retenir pour notre éditeur de samples :** faire voir immédiatement le
fichier, la waveform, les pads et le résultat préparé ; limiter les panneaux
avant que l’utilisateur ait une première réussite.

## 4. Novation Components

Components regroupe firmware, packs sonores, gestion de contenu et
personnalisation d’un appareil, avec une version web et une version standalone
pour le hors-ligne.

Source : [Novation Components](https://us.novationmusic.com/components).

**À retenir pour notre Hub :** présenter le produit comme un gestionnaire
d’atelier : appareil sélectionné, contenu, firmware, personnalisation et
état de connexion. Le coffre Studio Hub peut devenir notre équivalent local,
avec une meilleure transparence sur les fichiers.

## Différenciation Studio Hub

Notre avantage crédible n’est pas de promettre un DAW généraliste. C’est de
rassembler :

- une identité unique pour plusieurs machines ;
- un coffre local et des snapshots sélectifs ;
- des éditeurs adaptés à l’OP‑1 et l’EP‑133 ;
- des explications claires sur ce qui est local, simulé ou réellement écrit ;
- un retour simple vers le Hub depuis chaque outil.

## Risques à éviter

- copier l’esthétique Teenage Engineering sans leur retenue fonctionnelle ;
- afficher trop de boutons techniques au même niveau ;
- cacher l’état de connexion dans un menu ;
- faire croire qu’un export local est déjà un transfert machine ;
- utiliser une couleur comme seul message d’erreur ou de succès.
