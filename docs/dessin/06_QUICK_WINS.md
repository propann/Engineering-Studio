# Livrables rapides pour rendre le produit crédible

Ces éléments peuvent être dessinés puis intégrés progressivement sans
modifier les fonctions métier.

## Lot 1 — en-têtes cohérents

- même hauteur Hub/OP‑1/EP‑133 ;
- nom du produit à gauche ;
- module actif au centre ;
- statut machine/MIDI visible ;
- `HUB OUTILS` à droite ;
- `ACCUEIL` distinct de `HUB OUTILS`.

## Lot 2 — cartes et icônes

- quatre cartes Hub ;
- sept à huit cartes OP‑1 ;
- cartes Accueil EP‑133 ;
- six icônes communes ;
- badges machine, workspace, MIDI et bridge.

## Lot 3 — états de confiance

- absence de machine ;
- connexion en cours ;
- machine connectée ;
- sauvegarde/restauration avec progression ;
- succès ;
- erreur avec bouton de reprise.

## Lot 4 — éditeur de samples

- import fichier ;
- waveform claire ;
- repères début/fin ;
- bouton `Préparer` ;
- résultat exporté ;
- distinction préparation/transfert.

## Lot 5 — crédibilité produit

- page Documentation accessible partout ;
- écran « ce qui reste local » ;
- écran « opération longue » ;
- confirmation avant suppression/restauration machine ;
- petit panneau « machine déclarée : nom · modèle · capacité ».

## Ce qui peut sortir vite sans risque

1. tokens de couleur et typographie ;
2. icônes SVG ligne ;
3. en-têtes et badges ;
4. cartes Hub ;
5. états vides et erreurs ;
6. panneau de progression ;
7. version étroite des barres de navigation.

## Ce qui doit attendre une validation technique

- bouton qui écrit réellement sur une machine ;
- promesse de synchronisation OP‑1 + EP‑133 ;
- restauration destructive sans confirmation ;
- affichage d’une capacité mémoire comme mesure réelle si elle n’a pas été
  lue sur l’appareil.
